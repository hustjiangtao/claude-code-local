# claude-code-local

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/wyh0626/claude-code-local)

Run Claude Code locally from source.

## Prerequisites

- [Bun](https://bun.sh) v1.3.11+
- `ANTHROPIC_API_KEY` environment variable — get one from [console.anthropic.com](https://console.anthropic.com)

## Deploy

```bash
git clone git@github.com:wyh0626/claude-code-local.git
cd claude-code-local
bun install
./run.sh
```

Or:

```bash
bun start
```
